# Ashen Marches

A top-down, turn-based dark-fantasy RPG built with Godot 4 and GDScript.

## Status

The repository is being initialized as a playable vertical slice. See `AGENTS.md` for project rules and `docs/GAME_DESIGN.md` for the scope.

## Run

Open `project.godot` in Godot 4.3 or newer and press F6/F5 (main scene is configured in the project).

## Controls

- WASD / arrows: move
- E: interact
- I: inventory
- Enter: confirm / end turn in combat
- Esc: pause / close panels
